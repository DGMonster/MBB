# MinimapButtonBag Reborn v1.0.6

## 🇬🇧 English

### ✨ New
- Added configurable **button scaling from 75% to 150%**.
- General MBB settings are now stored **account-wide**.
- The exclude list remains **character-specific**.
- Added an **in-game version check** using the WoW addon communication channel.
- Added localized update notifications when a newer MBB version is detected.

### 🔧 Fixed
- Fixed **middle mouse button support** for collected minimap buttons.
- Addons can now correctly receive middle-click actions.
- Fixed button visibility after an addon hides or disables its own minimap button.
- Improved Show/Hide handling for collected minimap buttons.
- Fixed `/mbb reset all` so account-wide settings are reset correctly.
- Fixed patch/interface detection for the unified multi-version TOC.

### 🎨 UI
- Improved the wording of the secondary row direction option.
- Button scaling now applies cleanly to the MBB button and collected addon buttons.

### 🌍 Localization
- Updated all supported localization files.
- Added translations for button scaling.
- Added translations for update notifications.
- Updated the wording of the secondary row direction setting.
- All localization files are synchronized again.

### 🎮 Supported WoW Versions
- World of Warcraft Retail
- WoW Classic Era
- The Burning Crusade Classic
- Mists of Pandaria Classic

- `/mbb reset all` korrigiert, damit accountweite Einstellungen zuverlässig zurückgesetzt werden.
